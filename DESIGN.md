# ODIN Pocket visual system

The desk of a careful editor, with the model's token choices visible in the margin. Product UI, restrained color. White workspace; a quiet neutral sidebar; deep orchid for selected actions and generated passages; pale blue for evidence. The palette seed supplied by the design skill replaces the provisional cobalt direction.

CSS roles: background oklch(1 0 0); surface oklch(.97 .004 280); ink oklch(.25 .025 290); primary oklch(.45 .15 330); accent oklch(.92 .035 245); muted oklch(.48 .018 290); border oklch(.88 .008 290).

System sans for interface, Georgia for passage and continuation, system monospace for token probabilities and numerical evidence. Fixed 14/16/20/28/40px hierarchy. Controls 42px minimum touch height. A 220px sidebar plus flexible workspace; sidebar becomes top navigation below 800px. Two-column reading area collapses below 1050px. Border radius 8px controls, 12px workspace edges. Focus ring visible on all controls. No decorative animation.

Signature: the continuation appears as an editable-document-style reading surface, with a probability ribbon whose cells correspond to real generated tokens. Evidence is a separate view with an actual loss curve and benchmark table, not invented values.
